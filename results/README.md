# Experimental results

This directory will hold selected numerical outputs and plots produced by the
canonical notebooks. No new experimental results are included in the repository
skeleton. Representative figures can remain embedded in their notebooks for
reading on GitHub.

When an export is needed, use a descriptive path such as
`optimization-and-variational-methods/vqe-h2/`. Place the figure or data table
beside a short account of the producing notebook, repository revision,
environment, parameters, and interpretation. Record seeds, shots, and execution
method when relevant, and distinguish local simulation from hardware execution.
Create experiment directories only when there is an actual result to store.
