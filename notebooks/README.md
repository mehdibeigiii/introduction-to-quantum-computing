# About the notebooks

The notebooks published on the CERN Indico page were written with an old version of Qiskit, so much of their code no longer works with the current API.

I used those notebooks to understand the original concepts, examples, and exercises. I then rewrote all of them using the newer Qiskit version used in this repository.

While rewriting them, I updated the imports, circuit execution, simulators, algorithms, and result handling while keeping the original learning purpose of each notebook.

The modernized notebooks are the main implementation files of this project. Their required packages and versions are listed in [`requirements.txt`](../requirements.txt).
